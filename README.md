# Wordle Clone
A wordle clone made in React. This is purely a React practice that I wanted to push out to GitHub. Took me two days, made with 5% AI (Importing Google Fonts in Tailwind and getting Github Pages to work)

# Tech Stack
- Bun
- ShadCN
- React
- Tailwind

# How to run
- `bun install`
- `bun dev`
